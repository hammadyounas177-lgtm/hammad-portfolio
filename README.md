## Local Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/hammadyounas177-lgtm/hammad-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd hammad-portfolio
   ```

3. Open `index.html` in a browser, or use the Live Server extension in VS Code for local development.

No package installation or build process is required. The project is a lightweight static website.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish the site, then open the generated URL.

For this project, the published site is available at:
